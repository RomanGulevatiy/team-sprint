## Quick Start

* Java 21
* Spring Boot 3.5.14
* PostgreSQL
* Docker

1. Clone the repository:
   ```bash
   git clone https://github.com/RomanGulevatiy/team-sprint.git
   cd team-sprint
   ```
2. Build the application using Maven:
   ```bash
   mvn clean install
   ```
3. Run the application:
   ```bash
   mvn spring-boot:run
   ```
